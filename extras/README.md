# Extras

This folder contains the following addons for the TextEditor widget:

- Simple trie-based autocomplete (see [documentation](../docs/autocomplete.md) for details).
- Language server bridge (see [documentation](../docs/lsp.md) for details).
- SourceIndex: the include tree and symbol table of C-like sources, for go to definition (see [documentation](../docs/goToDefinition.md) for details).
- FileWatcher: files added, modified and removed under folders, on any platform (see [documentation](../docs/goToDefinition.md) for details).
